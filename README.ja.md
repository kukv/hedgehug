# hedgehug

[English](README.md)

git を保存と同期の層に使う、ローカルファーストのタスク管理ツールです。CLI と GUI を1つのバイナリで提供します。

Linux と macOS で動きます。Windows では WSL の中で使ってください。

> **状態: セットアップ中。** CI、lint、リリースの設定を整えた段階で、機能はまだありません。まだ使える状態ではありません。
