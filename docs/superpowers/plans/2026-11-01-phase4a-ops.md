# フェーズ 4a: 操作の層（internal/ops） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `cmd/hedgehug`（package main）にある操作の本体を、表示から切り離して `internal/ops` に移し、CLI の挙動を1バイトも変えずに、CLI と後の GUI サーバーが同じ関数を呼べるようにする。

**Architecture:** `ops.Session` が設定・パス・書き手・開いた Store を持ち、操作はその上のメソッドとして型付きの結果を返す（何も印字しない）。エラーは `ops.Error`（Kind・Code・Args と元のエラー）で包み、`Error()` は元の文言をそのまま返す。`cmd/hedgehug` には cobra・フラグ・テキストと JSON の出力・確認・`$EDITOR` だけを残す。

**Tech Stack:** Go 1.27、cobra、既存の internal パッケージ（store・index・config・sync・inbox・query・schema・doctor・merge・gitrepo）

**Spec:** `docs/superpowers/specs/2026-11-01-phase4-gui-design.md`（「4a 操作の層（internal/ops）」）

## Global Constraints

- 挙動を変えない。`cmd/hedgehug` の既存のテスト（ゴールデン、シナリオ、e2e）を、期待値（`testdata/**.golden` とテスト内の期待値）を1つも変えずに通す。`go test ./cmd/hedgehug/... -update` は実行しない
- 終了コードを変えない: 0 成功、2 フラグ・引数の誤り（`Usage`）、1 それ以外
- エラーの文言を変えない。`ops.Error.Error()` は包んだエラーの `Error()` をそのまま返す
- `internal/ops` は何も印字しない（stdout・stderr に書かない）。警告は `Session.Warn` に渡す
- 移した操作ごとに `internal/ops` に単体テストを置く（利用者の決定）
- 用語: 人が読める識別子は ID、内部の識別子は ULID
- コードのコメント・識別子は英語（既存のコードに合わせる）。コミットメッセージは日本語で、`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` を付ける
- 各タスクの最後に `go test -race ./...` と `golangci-lint run ./...` と `golangci-lint fmt --diff ./...` を通す
- コミットの署名は既存の設定（1Password）に任せる。署名に失敗したら止まって利用者に知らせる

## エラーの種類

| Kind | 意味 | CLI の終了コード |
|---|---|---|
| `KindNotFound` | ID・ULID・名前が見つからない | 1 |
| `KindAmbiguous` | ID の指定が複数に当たる | 1 |
| `KindInvalid` | 検証・スキーマ違反、不正な値 | 1 |
| `KindConflict` | 削除済み、親が削除済み、ロック中などで今は実行できない | 1 |
| `KindUsage` | 引数の組み合わせの誤り | 2 |

`Code` はドットで区切った小文字の英字（`task.not_found` など）で、GUI が文言を選ぶのに使う。各タスクの表に、そのタスクで包むエラーと Code を挙げる。表にない `fmt.Errorf`・`errors.New` は、Kind を付けずにそのまま返してよい（HTTP では 500 になる。4c でそう扱う）。

- [ ] **Step 4: errors.go を書く**

```go
// Package ops holds the operations of hedgehug that the CLI and the GUI
// server share. They return typed results and print nothing.
package ops

import (
	"errors"

	"github.com/kukv/hedgehug/internal/config"
	"github.com/kukv/hedgehug/internal/index"
	"github.com/kukv/hedgehug/internal/store"
)

// Kind is what an error means to the caller: the CLI turns it into an exit
// code, the server into an HTTP status.
type Kind int

const (
	KindUnknown Kind = iota
	KindNotFound
	KindAmbiguous
	KindInvalid
	KindConflict
	KindUsage
)

// Error is an error of an operation. Its message is the wrapped error's, so
// the CLI prints what it printed before; Code and Args let the GUI choose
// its own words.
type Error struct {
	Kind Kind
	Code string
	Args map[string]any
	Err  error
}

func (e *Error) Error() string { return e.Err.Error() }
func (e *Error) Unwrap() error { return e.Err }

// newErr wraps err; args are key, value pairs.
func newErr(k Kind, code string, err error, args ...any) *Error {
	e := &Error{Kind: k, Code: code, Err: err}
	if len(args) > 0 {
		e.Args = map[string]any{}
		for i := 0; i+1 < len(args); i += 2 {
			e.Args[args[i].(string)] = args[i+1]
		}
	}
	return e
}

// KindOf is the Kind of err: that of the outermost *Error, or the one the
// error of a lower layer stands for.
func KindOf(err error) Kind {
	var e *Error
	if errors.As(err, &e) {
		return e.Kind
	}
	return classify(err).Kind
}

// classify gives the errors of the lower layers a Kind and a Code.
func classify(err error) *Error {
	var ae *index.AmbiguousError
	var ve *store.ValidationError
	switch {
	case err == nil:
		return nil
	case errors.As(err, &ae):
		return newErr(KindAmbiguous, "task.ambiguous", err, "input", ae.Input)
	case errors.Is(err, store.ErrNotFound):
		return newErr(KindNotFound, "task.not_found", err)
	case errors.As(err, &ve):
		return newErr(KindInvalid, "schema.violation", err)
	case errors.Is(err, store.ErrLocked):
		return newErr(KindConflict, "store.locked", err)
	case errors.Is(err, config.ErrNoStores):
		return newErr(KindConflict, "store.none", err)
	}
	return &Error{Kind: KindUnknown, Err: err}
}
```

```go
func (ss *Session) warn(msg string) {
	if ss.Warn != nil {
		ss.Warn(msg)
	}
}

// MarkWritten notes that s has a commit to push and hands the write to
// AfterWrite. The commit is made, so a failure here is only a warning.
func (ss *Session) markWritten(s *store.Store) {
	if err := sync.MarkPending(s, ss.Now()); err != nil {
		ss.warn("the write is not marked for sync: " + err.Error())
		return
	}
	if ss.AfterWrite == nil {
		return
	}
	_, e, err := ss.Entry()
	if err != nil {
		return
	}
	ss.AfterWrite(s, e)
}
```
