# フェーズ 1d-1: CLI の基盤とタスク操作 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1a〜1c の Core の上に、設定と場所（`HEDGEHUG_HOME`）、Store の選び方、`store init`、タスクの CRUD とツリー表示、出力形式を持つ cobra の CLI を作る。

**Architecture:** `internal/config` が環境変数（関数で注入）から設定ファイルと Store の置き場所を決め、`config.yaml` を `yaml.Node` で読み書きし、git のグローバル設定から作者を読む。`cmd/hedgehug` は cobra のコマンドを `app` 構造体のメソッドで組み、コマンドごとに Store と index を開いて、書き込みは `Store.Update` 1回（1コミット）で行う。出力は表（tabwriter）・ツリー・JSON・Go テンプレートを `output.go` に集める。

**Tech Stack:** Go 1.27.3、`github.com/spf13/cobra`（新規）、`golang.org/x/term`（新規）、`github.com/go-git/go-git/v5` v5.19.3（`plumbing/format/config` で gitconfig を読む）、`go.yaml.in/yaml/v4`

**Spec:** `docs/superpowers/specs/2026-10-30-phase1d1-cli-design.md`（実装前に必ず読む）

## Global Constraints

- モジュールは `github.com/kukv/hedgehug`、Go は `go 1.27.3`（`go.mod` のまま）。新しい依存は `github.com/spf13/cobra` と `golang.org/x/term` だけ（Task 5 で足す）。
- 依存の向きは `cmd/hedgehug → query → index → store → schema → model`、`cmd/hedgehug → config`、`config → gitrepo`。`config` は `store`・`index`・`schema` を import しない。
- テストは標準の `testing` だけで書く（testify などは使わない）。テストは対象と同じパッケージに置く。既存のテストの書き方（`t.Fatal`、`t.Errorf("... = %v, want %v")`）に合わせる。
- 環境変数は `os.Getenv` を直接呼ばず、`getenv func(string) string` を引数で受ける（テストを並列にでき、プロセスの環境を書き換えないため）。`os.UserHomeDir` / `os.UserConfigDir` も使わない（中で環境変数を読むため）。
- コード中のコメントは英語（既存コードに合わせる）。CLI の出力メッセージも英語。コミットメッセージは日本語の Conventional Commits（例: `feat: ...`）で、末尾に空行を挟んで `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` を付ける。
- 各タスクの最後に `make check`（tidy-check・lint・fmt-check・test）を通す。lint は golangci-lint の standard に revive・gosec・gocritic・unparam などを足したもの（`.golangci.yaml`）。gosec がパス変数の読み書き（G304 など）を指摘したら、`//nolint:gosec // <理由>` を付ける。理由は具体的に書く。gocritic の ifElseChain は switch に書き換える。
- CI は ubuntu / macos / windows の matrix でテストを回す。手元では `GOOS=windows go vet ./...` と `GOOS=darwin go vet ./...` でコンパイルを確かめる。テストでパスを比べるときは `filepath.Join` で組む。
- ファイルのパーミッションは 0600、ディレクトリは 0750。
- 終了コード: 成功 0、実行時のエラー 1、フラグや引数の誤り 2、`-h` は 0。エラーは stderr に `hedgehug: <理由>` の1行（違反や候補は続く行に字下げして並べる）。
- Op 名: `add`、`set`、`status`（`status` と `done`）、`rm`、`restore`、`purge`、`mv`、`dep`（`dep add` と `dep rm`）。`store init` は `store.Create` の `init` コミット。

## spec からの細部の確定（spec は Task 14 で直す）

- 作者は go-git の `config.LoadConfig(GlobalScope)` ではなく、`getenv` から決めたパスの gitconfig を `plumbing/format/config` の Decoder で読む。`GIT_CONFIG_GLOBAL` があればそのファイルだけ、なければ `$XDG_CONFIG_HOME/git/config`（XDG がなければ `~/.config/git/config`）、`~/.gitconfig` の順に読み、後のファイルが勝つ（git と同じ）。`LoadConfig` はプロセスの環境変数を読むため、テストから注入できない。
- `ls --tree` は兄弟を常に rank の順に並べる。`sort:` と `group:` はどちらも `--tree` と併用するとエラー（使い方の誤り、終了コード 2）。
- `add` / `done` の既定のステータスは `Schema.DefaultStatus(category)` で引く。プロジェクトの上書きはカテゴリの既定を外せない（親設計）ので、置き場所によらず同じになる。

```go
// newStoreHook lets tests change the store Create made before it writes.
var newStoreHook = func(*Store) {}

// Create makes a new store in dir, which must be missing or empty: a git
// repository holding store.yaml, sc as schema.yaml (the default schema when
// sc is nil) and a .gitignore, in one commit. meta is copied, not changed.
// When Create fails it removes what it made, so it can be run again.
func Create(dir string, meta *model.StoreMeta, sc *schema.Schema, author gitrepo.Signature) (_ *Store, err error) {
	made, err := ensureEmpty(dir)
	if err != nil {
		return nil, err
	}
	defer func() {
		if err != nil {
			err = errors.Join(err, undoCreate(dir, made))
		}
	}()
	repo, err := gitrepo.Init(dir)
	if err != nil {
		return nil, err
	}
	m := *meta
	m.Format = model.StoreFormat
	if sc == nil {
		sc = schema.Default()
	}
	s := newStore(dir, repo, &m, sc)
	newStoreHook(s)

	mb, err := m.Encode()
	if err != nil {
		return nil, err
	}
	sb, err := s.Schema().Encode()
	if err != nil {
		return nil, err
	}
	// （ここから下の files・writeFile・s.commit の部分は既存のまま）
	...
	return s, nil
}

// ensureEmpty makes sure dir is an empty directory, creating it when it is
// missing. made tells whether it created it.
func ensureEmpty(dir string) (made bool, err error) {
	entries, err := os.ReadDir(dir)
	if errors.Is(err, fs.ErrNotExist) {
		return true, os.MkdirAll(dir, 0o750)
	}
	if err != nil {
		return false, err
	}
	if len(entries) > 0 {
		return false, fmt.Errorf("%s is not empty", dir)
	}
	return false, nil
}

// undoCreate removes what a failed Create left in dir: dir itself when
// Create made it, its contents otherwise.
func undoCreate(dir string, made bool) error {
	if made {
		return os.RemoveAll(dir)
	}
	entries, err := os.ReadDir(dir)
	if err != nil {
		return err
	}
	var errs []error
	for _, e := range entries {
		errs = append(errs, os.RemoveAll(filepath.Join(dir, e.Name())))
	}
	return errors.Join(errs...)
}
```

`...` の部分は既存の `files` の組み立て、`writeFile` のループ、`s.commit(...)` をそのまま残す。`meta.Encode()` を `m.Encode()` にする点だけが変わる。`MkdirAll` が途中まで作ってから失敗した場合（`made` が true でエラー）は、`ensureEmpty` のエラーをそのまま返す（後始末はしない。何も作れていないことが多いため）。

```go
// Package config finds where Hedgehug keeps its settings and stores, reads
// and writes config.yaml, and finds the author of commits.
package config

import (
	"errors"
	"path/filepath"
	"runtime"
)

// goos is runtime.GOOS; tests replace it.
var goos = runtime.GOOS

// Paths is where the settings and the stores are, as absolute paths.
type Paths struct {
	Home       string // the user's home directory
	ConfigFile string // config.yaml
	StoresDir  string // the directory new stores go in, one per name
}

// Resolve finds the paths. HEDGEHUG_HOME holds both config.yaml and stores/
// when set; otherwise XDG_CONFIG_HOME and XDG_DATA_HOME are looked at each on
// its own, then the defaults of the OS. Relative values are ignored, as the
// XDG spec says.
func Resolve(getenv func(string) string) (Paths, error) {
	h, err := home(getenv)
	if err != nil {
		return Paths{}, err
	}
	p := Paths{Home: h}
	if hh := abs(getenv("HEDGEHUG_HOME")); hh != "" {
		p.ConfigFile = filepath.Join(hh, "config.yaml")
		p.StoresDir = filepath.Join(hh, "stores")
		return p, nil
	}
	cfg := abs(getenv("XDG_CONFIG_HOME"))
	if cfg == "" {
		cfg = defaultConfigDir(getenv, h)
	}
	data := abs(getenv("XDG_DATA_HOME"))
	if data == "" {
		data = defaultDataDir(getenv, h)
	}
	p.ConfigFile = filepath.Join(cfg, "hedgehug", "config.yaml")
	p.StoresDir = filepath.Join(data, "hedgehug", "stores")
	return p, nil
}

// home is the user's home directory: USERPROFILE on Windows, HOME elsewhere.
func home(getenv func(string) string) (string, error) {
	key := "HOME"
	if goos == "windows" {
		key = "USERPROFILE"
	}
	h := abs(getenv(key))
	if h == "" {
		return "", errors.New("the home directory is not known: $" + key + " is not set to an absolute path")
	}
	return h, nil
}

func defaultConfigDir(getenv func(string) string, home string) string {
	switch goos {
	case "windows":
		if d := abs(getenv("APPDATA")); d != "" {
			return d
		}
		return filepath.Join(home, "AppData", "Roaming")
	case "darwin":
		return filepath.Join(home, "Library", "Application Support")
	default:
		return filepath.Join(home, ".config")
	}
}

func defaultDataDir(getenv func(string) string, home string) string {
	if goos == "windows" {
		if d := abs(getenv("LOCALAPPDATA")); d != "" {
			return d
		}
		return filepath.Join(home, "AppData", "Local")
	}
	return filepath.Join(home, ".local", "share")
}

// abs returns p when it is an absolute path, and "" otherwise.
func abs(p string) string {
	if p == "" || !filepath.IsAbs(p) {
		return ""
	}
	return filepath.Clean(p)
}
```

```go
package config

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"regexp"
	"strings"

	"go.yaml.in/yaml/v4"
)

// ErrNoStores means config.yaml lists no store.
var ErrNoStores = errors.New("no store is set up; run hedgehug store init <name>")

// StoreEntry is one store in config.yaml.
type StoreEntry struct {
	Name string
	Path string // absolute, with ~/ expanded
}

// Config is config.yaml. Only stores[].name and stores[].path are read;
// the rest of the file, comments included, is kept as it was by Save.
type Config struct {
	Stores []StoreEntry

	file string
	home string
	doc  *yaml.Node // the document; nil when the file does not exist
}

// Load reads config.yaml. A missing file is a config with no stores.
func Load(p Paths) (*Config, error) {
	c := &Config{file: p.ConfigFile, home: p.Home}
	b, err := os.ReadFile(p.ConfigFile) //nolint:gosec // the path is the user's own config file
	if errors.Is(err, fs.ErrNotExist) {
		return c, nil
	}
	if err != nil {
		return nil, err
	}
	var doc yaml.Node
	if err := yaml.Load(b, &doc); err != nil {
		if strings.Contains(err.Error(), "no documents") {
			return c, nil
		}
		return nil, fmt.Errorf("%s: %w", c.file, err)
	}
	if doc.Kind == 0 || len(doc.Content) == 0 {
		return c, nil
	}
	root := doc.Content[0]
	if root.Kind != yaml.MappingNode {
		return nil, c.errAt(root, "want a mapping")
	}
	c.doc = &doc
	seq := valueOf(root, "stores")
	if seq == nil {
		return c, nil
	}
	if seq.Kind != yaml.SequenceNode {
		return nil, c.errAt(seq, "stores: want a list")
	}
	seen := map[string]bool{}
	for _, it := range seq.Content {
		if it.Kind != yaml.MappingNode {
			return nil, c.errAt(it, "stores: want a mapping with name and path")
		}
		name, path := valueOf(it, "name"), valueOf(it, "path")
		if name == nil || name.Value == "" {
			return nil, c.errAt(it, "stores: name is missing")
		}
		if path == nil || path.Value == "" {
			return nil, c.errAt(it, "stores: path is missing")
		}
		if seen[name.Value] {
			return nil, c.errAt(it, fmt.Sprintf("stores: %q is listed twice", name.Value))
		}
		seen[name.Value] = true
		c.Stores = append(c.Stores, StoreEntry{Name: name.Value, Path: c.expand(path.Value)})
	}
	return c, nil
}

// Select picks the store a command works on: the one named name, or the
// only one when name is empty.
func (c *Config) Select(name string) (StoreEntry, error) {
	if len(c.Stores) == 0 {
		return StoreEntry{}, ErrNoStores
	}
	names := make([]string, len(c.Stores))
	for i, s := range c.Stores {
		if s.Name == name {
			return s, nil
		}
		names[i] = s.Name
	}
	if name != "" {
		return StoreEntry{}, fmt.Errorf("no store is named %q (stores: %s)", name, strings.Join(names, ", "))
	}
	if len(c.Stores) == 1 {
		return c.Stores[0], nil
	}
	return StoreEntry{}, fmt.Errorf("several stores are set up; pick one with --store (stores: %s)", strings.Join(names, ", "))
}

// AddStore adds a store to the end of stores. Save writes it.
func (c *Config) AddStore(name, path string) error {
	for _, s := range c.Stores {
		if s.Name == name {
			return fmt.Errorf("a store named %q is already set up", name)
		}
	}
	if c.doc == nil {
		c.doc = &yaml.Node{Kind: yaml.DocumentNode, Content: []*yaml.Node{{Kind: yaml.MappingNode, Tag: "!!map"}}}
	}
	root := c.doc.Content[0]
	seq := valueOf(root, "stores")
	if seq == nil {
		seq = &yaml.Node{Kind: yaml.SequenceNode, Tag: "!!seq"}
		root.Content = append(root.Content, scalar("stores"), seq)
	}
	seq.Content = append(seq.Content, &yaml.Node{Kind: yaml.MappingNode, Tag: "!!map", Content: []*yaml.Node{
		scalar("name"), scalar(name),
		scalar("path"), scalar(c.shorten(path)),
	}})
	c.Stores = append(c.Stores, StoreEntry{Name: name, Path: path})
	return nil
}

// Save writes config.yaml through a temporary file and a rename.
func (c *Config) Save() error {
	if c.doc == nil {
		return nil
	}
	b, err := yaml.Dump(c.doc, yaml.WithLineWidth(-1))
	if err != nil {
		return err
	}
	dir := filepath.Dir(c.file)
	if err := os.MkdirAll(dir, 0o750); err != nil {
		return err
	}
	f, err := os.CreateTemp(dir, ".config.yaml.tmp-*")
	if err != nil {
		return err
	}
	tmp := f.Name()
	_, err = f.Write(b)
	if cerr := f.Close(); err == nil {
		err = cerr
	}
	if err == nil {
		err = os.Rename(tmp, c.file)
	}
	if err != nil {
		_ = os.Remove(tmp)
	}
	return err
}

var storeNameRE = regexp.MustCompile(`^[a-z0-9][a-z0-9_-]*$`)

// ValidStoreName reports whether name can name a store: lower-case letters,
// digits, - and _, starting with a letter or a digit. The name is also the
// directory of the store.
func ValidStoreName(name string) error {
	if !storeNameRE.MatchString(name) {
		return fmt.Errorf("%q cannot name a store: use lower-case letters, digits, - and _, starting with a letter or a digit", name)
	}
	return nil
}

func (c *Config) errAt(n *yaml.Node, msg string) error {
	return fmt.Errorf("%s:%d: %s", c.file, n.Line, msg)
}

// expand turns a leading ~/ into the home directory.
func (c *Config) expand(p string) string {
	if rest, ok := strings.CutPrefix(p, "~/"); ok {
		return filepath.Join(c.home, filepath.FromSlash(rest))
	}
	return filepath.Clean(filepath.FromSlash(p))
}

// shorten writes p under the home directory as ~/..., with slashes.
func (c *Config) shorten(p string) string {
	if rel, err := filepath.Rel(c.home, p); err == nil && rel != "." && !strings.HasPrefix(rel, "..") && !filepath.IsAbs(rel) {
		return "~/" + filepath.ToSlash(rel)
	}
	return filepath.ToSlash(p)
}

// valueOf returns the value of key in the mapping m, or nil.
func valueOf(m *yaml.Node, key string) *yaml.Node {
	for i := 0; i+1 < len(m.Content); i += 2 {
		if m.Content[i].Value == key {
			return m.Content[i+1]
		}
	}
	return nil
}

func scalar(v string) *yaml.Node { return &yaml.Node{Kind: yaml.ScalarNode, Tag: "!!str", Value: v} }
```

```go
package config

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"

	gitconfig "github.com/go-git/go-git/v5/plumbing/format/config"

	"github.com/kukv/hedgehug/internal/gitrepo"
)

// Author returns the author of commits: user.name and user.email of the
// user's global git config. GIT_CONFIG_GLOBAL names the only file to read
// when set; otherwise the XDG file and ~/.gitconfig are read in that order,
// the later winning, as git does. Accounts replace this in phase 3.
func Author(getenv func(string) string) (gitrepo.Signature, error) {
	var files []string
	if g := getenv("GIT_CONFIG_GLOBAL"); g != "" {
		files = []string{g}
	} else {
		h, err := home(getenv)
		if err != nil {
			return gitrepo.Signature{}, err
		}
		x := abs(getenv("XDG_CONFIG_HOME"))
		if x == "" {
			x = filepath.Join(h, ".config")
		}
		files = []string{filepath.Join(x, "git", "config"), filepath.Join(h, ".gitconfig")}
	}
	var sig gitrepo.Signature
	for _, f := range files {
		b, err := os.Open(f) //nolint:gosec // the path is the user's own git config
		if errors.Is(err, fs.ErrNotExist) {
			continue
		}
		if err != nil {
			return gitrepo.Signature{}, err
		}
		cfg := gitconfig.New()
		err = gitconfig.NewDecoder(b).Decode(cfg)
		_ = b.Close()
		if err != nil {
			return gitrepo.Signature{}, fmt.Errorf("%s: %w", f, err)
		}
		u := cfg.Section("user")
		if v := u.Option("name"); v != "" {
			sig.Name = v
		}
		if v := u.Option("email"); v != "" {
			sig.Email = v
		}
	}
	switch {
	case sig.Name == "":
		return sig, errors.New("the author is not known: set it with git config --global user.name <name>")
	case sig.Email == "":
		return sig, errors.New("the author is not known: set it with git config --global user.email <email>")
	}
	return sig, nil
}
```

```go
// Command hedgehug is a local-first task manager that uses git as its storage
// and sync layer, with a CLI and a GUI in a single binary.
package main

import (
	"errors"
	"fmt"
	"io"
	"os"
	"strings"
	"time"

	"golang.org/x/term"
)

// version is what --version prints. GoReleaser sets it with -ldflags at
// release build time.
var version = "dev"

// env is what one run of the command sees of the world outside.
type env struct {
	stdin          io.Reader
	stdout, stderr io.Writer
	getenv         func(string) string
	isTerminal     func(any) bool // reports whether a stream is a terminal
	now            func() time.Time
}

func main() {
	os.Exit(run(os.Args[1:], &env{
		stdin:      os.Stdin,
		stdout:     os.Stdout,
		stderr:     os.Stderr,
		getenv:     os.Getenv,
		isTerminal: isTerminal,
		now:        time.Now,
	}))
}

func isTerminal(f any) bool {
	file, ok := f.(*os.File)
	return ok && term.IsTerminal(int(file.Fd())) //nolint:gosec // a file descriptor fits in an int
}

// run runs the command and returns its exit code: 0 on success, 2 for a
// mistake in flags or arguments, 1 for any other error.
func run(args []string, e *env) int {
	a := &app{env: e}
	root := a.rootCmd()
	root.SetArgs(args)
	root.SetIn(e.stdin)
	root.SetOut(e.stdout)
	root.SetErr(e.stderr)
	err := root.Execute()
	if err == nil {
		return 0
	}
	writeErr(e.stderr, err)
	var ue usageError
	if errors.As(err, &ue) || strings.HasPrefix(err.Error(), "unknown command") {
		return 2
	}
	return 1
}

// writeErr prints err as hedgehug: <reason>, with the details of the errors
// that carry a list on the lines after it.
func writeErr(w io.Writer, err error) {
	_, _ = fmt.Fprintln(w, "hedgehug: "+describe(err))
}
```

```go
import (
	"errors"

// app holds the global flags and what the commands share.
type app struct {
	*env
	storeName string
	jsonOut   bool
	noColor   bool
}

// usageError is a mistake in the flags or arguments; it exits 2.
type usageError struct{ error }

func (e usageError) Unwrap() error { return e.error }

func usageErrorf(format string, args ...any) error {
	return usageError{fmt.Errorf(format, args...)}
}

func (a *app) rootCmd() *cobra.Command {
	root := &cobra.Command{
		Use:           "hedgehug",
		Short:         "A local-first task manager on git",
		Version:       version,
		SilenceErrors: true,
		SilenceUsage:  true,
		Args:          cobra.NoArgs,
		// completion comes in phase 7.
		CompletionOptions: cobra.CompletionOptions{DisableDefaultCmd: true},
		RunE: func(cmd *cobra.Command, _ []string) error {
			cmd.SetOut(cmd.ErrOrStderr())
			_ = cmd.Usage()
			return usageErrorf("a command is needed")
		},
	}
	root.SetVersionTemplate("hedgehug {{.Version}}\n")
	root.SetFlagErrorFunc(func(_ *cobra.Command, err error) error { return usageError{err} })
	pf := root.PersistentFlags()
	pf.StringVar(&a.storeName, "store", "", "the store to work on, by name")
	pf.BoolVar(&a.jsonOut, "json", false, "print JSON")
	pf.BoolVar(&a.noColor, "no-color", false, "do not color the output")
	root.AddCommand(a.storeCmd(), a.lsCmd())
	return root
}

// exactArgs and minArgs are cobra's, with the error as a usageError.
func exactArgs(n int) cobra.PositionalArgs { return asUsage(cobra.ExactArgs(n)) }
func minArgs(n int) cobra.PositionalArgs   { return asUsage(cobra.MinimumNArgs(n)) }

func asUsage(f cobra.PositionalArgs) cobra.PositionalArgs {
	return func(cmd *cobra.Command, args []string) error {
		if err := f(cmd, args); err != nil {
			return usageError{err}
		}
		return nil
	}
}

func (a *app) config() (*config.Config, config.Paths, error) {
	p, err := config.Resolve(a.getenv)
	if err != nil {
		return nil, p, err
	}
	c, err := config.Load(p)
	return c, p, err
}

// openStore opens the store the command works on.
func (a *app) openStore() (*store.Store, error) {
	c, _, err := a.config()
	if err != nil {
		return nil, err
	}
	e, err := c.Select(a.storeName)
	if err != nil {
		return nil, err
	}
	return store.Open(e.Path)
}

// open opens the store and its index.
func (a *app) open() (*store.Store, *index.Index, error) {
	s, err := a.openStore()
	if err != nil {
		return nil, nil, err
	}
	ix, err := index.Open(s)
	if err != nil {
		return nil, nil, err
	}
	return s, ix, nil
}

// update runs one operation, named name and about task, as one commit.
func (a *app) update(s *store.Store, name string, task model.ID, fn func(*store.Tx) error) error {
	author, err := config.Author(a.getenv)
	if err != nil {
		return err
	}
	return s.Update(store.Op{Name: name, Task: task, Author: author}, fn)
}

// resolve finds the task arg names.
func (a *app) resolve(ix *index.Index, arg string) (*index.Entry, error) {
	id, err := ix.Resolve(arg)
	if err != nil {
		return nil, err
	}
	e, _ := ix.Task(id)
	return e, nil
}

// describe turns err into the text after "hedgehug: ". Task 6 makes it
// list violations and candidates.
func describe(err error) string {
	return err.Error()
}
```

```go
package main

import (
	"encoding/json"
)

// style colors text when the output is a terminal.
type style struct{ on bool }

func (a *app) style() style {
	return style{on: !a.noColor && a.getenv("NO_COLOR") == "" && a.isTerminal(a.stdout)}
}

func (s style) wrap(code, t string) string {
	if !s.on {
		return t
	}
	return "\x1b[" + code + "m" + t + "\x1b[0m"
}

// id colors a short ID.
func (s style) id(t string) string { return s.wrap("33", t) }

// dim marks text that is context, not a result. Without color it is put in
// parentheses.
func (s style) dim(t string) string {
	if !s.on {
		return "(" + t + ")"
	}
	return s.wrap("2", t)
}

// printJSON writes v as indented JSON.
func (a *app) printJSON(v any) error {
	enc := json.NewEncoder(a.stdout)
	enc.SetIndent("", "  ")
	return enc.Encode(v)
}
```

```go
package main

import (
	"errors"
	"fmt"
	"os"
	"path/filepath"

	"github.com/spf13/cobra"

	"github.com/kukv/hedgehug/internal/config"
	"github.com/kukv/hedgehug/internal/model"
	"github.com/kukv/hedgehug/internal/schema"
	"github.com/kukv/hedgehug/internal/store"
)

func (a *app) storeCmd() *cobra.Command {
	cmd := &cobra.Command{Use: "store", Short: "Manage stores", Args: cobra.NoArgs}
	cmd.AddCommand(a.storeInitCmd())
	return cmd
}

func (a *app) storeInitCmd() *cobra.Command {
	var template string
	cmd := &cobra.Command{
		Use:   "init <name>",
		Short: "Create a store",
		Args:  exactArgs(1),
		RunE: func(_ *cobra.Command, args []string) error {
			var sc *schema.Schema
			switch template {
			case "":
			case "dev":
				sc = schema.Dev()
			default:
				return usageErrorf("--template: %q is not a template; the one there is is dev", template)
			}
			return a.storeInit(args[0], sc)
		},
	}
	cmd.Flags().StringVar(&template, "template", "", "start from a template: dev adds a review status")
	return cmd
}

func (a *app) storeInit(name string, sc *schema.Schema) error {
	if err := config.ValidStoreName(name); err != nil {
		return err
	}
	c, p, err := a.config()
	if err != nil {
		return err
	}
	for _, e := range c.Stores {
		if e.Name == name {
			return fmt.Errorf("a store named %q is already set up", name)
		}
	}
	author, err := config.Author(a.getenv)
	if err != nil {
		return err
	}
	dir := filepath.Join(p.StoresDir, name)
	if _, err := store.Create(dir, &model.StoreMeta{ID: model.NewID(), Name: name}, sc, author); err != nil {
		return err
	}
	if err := c.AddStore(name, dir); err != nil {
		return errors.Join(err, os.RemoveAll(dir))
	}
	if err := c.Save(); err != nil {
		return errors.Join(err, os.RemoveAll(dir))
	}
	if a.jsonOut {
		return a.printJSON(struct {
			Name string `json:"name"`
			Path string `json:"path"`
		}{name, dir})
	}
	_, err = fmt.Fprintf(a.stdout, "Created store %s at %s\n", name, dir)
	return err
}
```

```go
package main

import (
	"fmt"
	"slices"
	"strconv"
	"strings"
	"time"

	"go.yaml.in/yaml/v4"

	"github.com/kukv/hedgehug/internal/model"
	"github.com/kukv/hedgehug/internal/schema"
)

// assign is one key=value of set and of add -p: = sets (an empty value
// clears), += adds to a list and -= removes from it.
type assign struct {
	key   string
	op    string // "=", "+=" or "-="
	value string
}

func parseAssign(s string) (assign, error) {
	i := strings.IndexByte(s, '=')
	if i < 0 {
		return assign{}, usageErrorf("%q: want key=value, key+=value or key-=value", s)
	}
	a := assign{key: s[:i], op: "=", value: s[i+1:]}
	if k, ok := strings.CutSuffix(a.key, "+"); ok {
		a.key, a.op = k, "+="
	} else if k, ok := strings.CutSuffix(a.key, "-"); ok {
		a.key, a.op = k, "-="
	}
	if a.key == "" {
		return assign{}, usageErrorf("%q: the key is missing", s)
	}
	return a, nil
}

func parseAssigns(ss []string) ([]assign, error) {
	out := make([]assign, 0, len(ss))
	for _, s := range ss {
		a, err := parseAssign(s)
		if err != nil {
			return nil, err
		}
		out = append(out, a)
	}
	return out, nil
}

// applyAssign changes t as a says. Built-in fields come first; any other key
// must be a property of sc, and its value is read by the property's type.
// resolve turns task names into IDs, for blocked_by and task_ref properties.
// Whether the result fits the schema is the store's to check.
func applyAssign(t *model.Task, a assign, sc *schema.Schema, resolve func(string) (model.ID, error)) error {
	switch a.key {
	case "title":
		return setScalar(&t.Title, a)
	case "kind":
		return setScalar(&t.Kind, a)
	case "status":
		return setScalar(&t.Status, a)
	case "assignees":
		return setList(&t.Assignees, a)
	case "watchers":
		return setList(&t.Watchers, a)
	case "labels":
		return setList(&t.Labels, a)
	case "repos":
		return setList(&t.Repos, a)
	case "blocked_by":
		return setIDs(&t.BlockedBy, a, resolve)
	case "parent", "rank":
		return fmt.Errorf("%s cannot be set; use hedgehug mv", a.key)
	}
	if slices.Contains(model.TaskKeys(), a.key) {
		return fmt.Errorf("%s cannot be set", a.key)
	}
	p, ok := sc.Prop(a.key)
	if !ok {
		return fmt.Errorf("%s is not a field or a property of the schema", a.key)
	}
	return setProp(t, p, a, resolve)
}

func setScalar(dst *string, a assign) error {
	if a.op != "=" {
		return fmt.Errorf("%s holds one value; use %s=<value>", a.key, a.key)
	}
	*dst = a.value
	return nil
}

func setList(dst *[]string, a assign) error {
	switch {
	case a.op == "=" && a.value == "":
		*dst = nil
	case a.value == "":
		return fmt.Errorf("%s%s: the value is missing", a.key, a.op)
	case a.op == "=":
		*dst = []string{a.value}
	case a.op == "+=":
		if !slices.Contains(*dst, a.value) {
			*dst = append(*dst, a.value)
		}
	default:
		*dst = slices.DeleteFunc(*dst, func(v string) bool { return v == a.value })
	}
	return nil
}

func setIDs(dst *[]model.ID, a assign, resolve func(string) (model.ID, error)) error {
	if a.op == "=" && a.value == "" {
		*dst = nil
		return nil
	}
	id, err := resolve(a.value)
	if err != nil {
		return fmt.Errorf("%s: %w", a.key, err)
	}
	switch a.op {
	case "=":
		*dst = []model.ID{id}
	case "+=":
		if !slices.Contains(*dst, id) {
			*dst = append(*dst, id)
		}
	default:
		*dst = slices.DeleteFunc(*dst, func(v model.ID) bool { return v == id })
	}
	return nil
}

func setProp(t *model.Task, p schema.Prop, a assign, resolve func(string) (model.ID, error)) error {
	multi := p.Multi || p.Type == schema.TypeMultiEnum
	if a.op == "=" && a.value == "" {
		t.Props.Delete(p.Name)
		return nil
	}
	if !multi && a.op != "=" {
		return fmt.Errorf("%s holds one value; use %s=<value>", a.key, a.key)
	}
	n, err := propValue(p, a.value, resolve)
	if err != nil {
		return err
	}
	if !multi {
		t.Props.Set(p.Name, n)
		return nil
	}
	var items []*yaml.Node
	if cur := t.Props.Get(p.Name); cur != nil && cur.Kind == yaml.SequenceNode {
		items = slices.Clone(cur.Content)
	}
	same := func(x *yaml.Node) bool { return x.Value == n.Value }
	switch a.op {
	case "=":
		items = []*yaml.Node{n}
	case "+=":
		if !slices.ContainsFunc(items, same) {
			items = append(items, n)
		}
	default:
		items = slices.DeleteFunc(items, same)
	}
	if len(items) == 0 {
		t.Props.Delete(p.Name)
		return nil
	}
	t.Props.Set(p.Name, &yaml.Node{Kind: yaml.SequenceNode, Tag: "!!seq", Content: items})
	return nil
}

// propValue reads v as a value of p. The tag makes the file show the value
// as its type: a text that looks like a number is quoted, a date is not.
func propValue(p schema.Prop, v string, resolve func(string) (model.ID, error)) (*yaml.Node, error) {
	tag := "!!str"
	bad := func(what string) error { return fmt.Errorf("%s: %q is not %s", p.Name, v, what) }
	switch p.Type {
	case schema.TypeNumber:
		_, ierr := strconv.ParseInt(v, 10, 64)
		_, ferr := strconv.ParseFloat(v, 64)
		switch {
		case ierr == nil:
			tag = "!!int"
		case ferr == nil:
			tag = "!!float"
		default:
			return nil, bad("a number")
		}
	case schema.TypeBool:
		b, err := strconv.ParseBool(v)
		if err != nil {
			return nil, bad("true or false")
		}
		v, tag = strconv.FormatBool(b), "!!bool"
	case schema.TypeDate:
		if _, err := model.ParseDate(v); err != nil {
			return nil, bad("a date (YYYY-MM-DD)")
		}
		tag = "!!timestamp"
	case schema.TypeDatetime:
		if _, err := time.Parse(time.RFC3339, v); err != nil {
			return nil, bad("a time (RFC 3339)")
		}
		tag = "!!timestamp"
	case schema.TypeDuration:
		if _, err := model.ParseDuration(v); err != nil {
			return nil, bad("a duration (like 2h30m)")
		}
	case schema.TypeTaskRef:
		id, err := resolve(v)
		if err != nil {
			return nil, fmt.Errorf("%s: %w", p.Name, err)
		}
		v = id.String()
	}
	return &yaml.Node{Kind: yaml.ScalarNode, Tag: tag, Value: v}, nil
}
```

```go
// writeTable writes rows under header, padding each column but the last
// to its widest cell. paint, when not nil, colors the padded cell of row r
// (-1 for the header) and column c; padding first keeps the escape codes
// out of the widths.
func writeTable(w io.Writer, header []string, rows [][]string, paint func(r, c int, s string) string) error {
	all := append([][]string{header}, rows...)
	widths := make([]int, len(header))
	for _, row := range all {
		for c, cell := range row {
			widths[c] = max(widths[c], utf8.RuneCountInString(cell))
		}
	}
	var b strings.Builder
	for r, row := range all {
		for c, cell := range row {
			if c < len(row)-1 {
				cell += strings.Repeat(" ", widths[c]-utf8.RuneCountInString(cell)) + "  "
			}
			if paint != nil {
				cell = paint(r-1, c, cell)
			}
			b.WriteString(cell)
		}
		b.WriteString("\n")
	}
	_, err := io.WriteString(w, b.String())
	return err
}
```

```go
type ambiguousError struct {
	input string
	lines []string // "<short>  <title>" per candidate
}

func (e *ambiguousError) Error() string {
	return fmt.Sprintf("%q matches %d tasks:\n  %s", e.input, len(e.lines), strings.Join(e.lines, "\n  "))
}

// resolve finds the task arg names.
func (a *app) resolve(ix *index.Index, arg string) (*index.Entry, error) {
	id, err := ix.Resolve(arg)
	var ae *index.AmbiguousError
	if errors.As(err, &ae) {
		lines := make([]string, len(ae.Candidates))
		for i, c := range ae.Candidates {
			e, _ := ix.Task(c)
			lines[i] = ix.ShortID(c) + "  " + e.Title
		}
		return nil, &ambiguousError{input: arg, lines: lines}
	}
	if err != nil {
		return nil, err
	}
	e, _ := ix.Task(id)
	return e, nil
}

// resolveID is resolve for applyAssign.
func (a *app) resolveID(ix *index.Index) func(string) (model.ID, error) {
	return func(s string) (model.ID, error) {
		e, err := a.resolve(ix, s)
		if err != nil {
			return model.ID{}, err
		}
		return e.ID, nil
	}
}

// describe turns err into the text after "hedgehug: ", with the violations
// of a refused write on the lines after it.
func describe(err error) string {
	var ve *store.ValidationError
	if errors.As(err, &ve) {
		var b strings.Builder
		b.WriteString("the change breaks the schema:")
		for _, v := range ve.Violations {
			b.WriteString("\n  " + v.String())
		}
		return b.String()
	}
	if errors.Is(err, store.ErrLocked) {
		return "another hedgehug is writing to the store; try again"
	}
	return err.Error()
}
```

```go
func (a *app) add(title, parentArg, kind, status string, assigns []assign) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	sc := ix.Schema()
	t := &model.Task{ID: model.NewID(), Title: title, Kind: kind, Status: status}
	if t.Kind == "" {
		k, ok := sc.DefaultKind()
		if !ok {
			return errors.New("the schema has no default kind; give one with --kind")
		}
		t.Kind = k.Name
	}
	if t.Status == "" {
		st, ok := sc.DefaultStatus(schema.CategoryTodo)
		if !ok {
			return errors.New("the schema has no default todo status; give one with --status")
		}
		t.Status = st.Name
	}
	if parentArg != "" {
		p, err := a.resolve(ix, parentArg)
		if err != nil {
			return err
		}
		t.Parent = &p.ID
	}
	for _, as := range assigns {
		if err := applyAssign(t, as, sc, a.resolveID(ix)); err != nil {
			return err
		}
	}
	if t.Rank, err = endRank(ix, t.Parent, t.ID); err != nil {
		return err
	}
	if err := a.update(s, "add", t.ID, func(tx *store.Tx) error { return tx.PutTask(t) }); err != nil {
		return err
	}
	return a.printTask(ix, t.ID, "Added")
}

// siblings returns the tasks under parent (the root when nil) that are not
// deleted, leaving out skip, by rank.
func siblings(ix *index.Index, parent *model.ID, skip model.ID) []*index.Entry {
	var all []*index.Entry
	if parent == nil {
		for _, e := range ix.Roots() {
			if e.Parent == nil {
				all = append(all, e)
			}
		}
	} else {
		all = ix.Children(*parent)
	}
	out := all[:0:0]
	for _, e := range all {
		if e.DeletedAt == nil && e.ID != skip {
			out = append(out, e)
		}
	}
	return out
}

// endRank returns a rank after every sibling under parent.
func endRank(ix *index.Index, parent *model.ID, skip model.ID) (model.Rank, error) {
	sib := siblings(ix, parent, skip)
	var last model.Rank
	if len(sib) > 0 {
		last = sib[len(sib)-1].Rank
	}
	return model.Between(last, "")
}
```

```go
	return cmd

func (a *app) ls(q *query.Query, idsOnly bool, tmpl *template.Template) error {
	_, ix, err := a.open()
	if err != nil {
		return err
	}
	res, err := query.Run(ix, q, query.Options{})
	if err != nil {
		var qe *query.Error
		if errors.As(err, &qe) {
			return usageError{err}
		}
		return err
	}
	var all []*index.Entry
	for _, g := range res.Groups {
		all = append(all, g.Tasks...)
	}
	switch {
	case idsOnly:
		return a.printIDs(ix, all)
	case tmpl != nil:
		return a.printFormat(ix, all, tmpl)
	case a.jsonOut || !hasTerm(q, "group"):
		return a.printTasks(ix, all)
	}
	for i, g := range res.Groups {
		key := g.Key
		if key == "" {
			key = "(none)"
		}
		if i > 0 {
			if _, err := fmt.Fprintln(a.stdout); err != nil {
				return err
			}
		}
		if _, err := fmt.Fprintf(a.stdout, "== %s (%d)\n", key, len(g.Tasks)); err != nil {
			return err
		}
		if err := a.printTasks(ix, g.Tasks); err != nil {
			return err
		}
	}
	return nil
}

func hasTerm(q *query.Query, key string) bool {
	for _, t := range q.Terms {
		if t.Key == key {
			return true
		}
	}
	return false
}

// printFormat runs tmpl on each task, with the task as --json has it: a map
// of the JSON field names.
func (a *app) printFormat(ix *index.Index, es []*index.Entry, tmpl *template.Template) error {
	for _, e := range es {
		b, err := json.Marshal(entryJSON(ix, e))
		if err != nil {
			return err

			return err
		}
		if _, err := fmt.Fprintln(a.stdout); err != nil {
			return err
		}
	}
	return nil
}
```

```go
package main

import (
	"cmp"
	"errors"
	"fmt"
	"slices"
	"strings"

// treeNode is one task in ls --tree.
type treeNode struct {
	e        *index.Entry
	context  bool // shown only to connect the tasks found
	children []*treeNode
}

func (a *app) lsTree(q *query.Query, idsOnly bool, tmpl *template.Template) error {
	if hasTerm(q, "group") || hasTerm(q, "sort") {
		return usageErrorf("--tree orders tasks by rank; it takes neither group: nor sort:")
	}
	_, ix, err := a.open()
	if err != nil {
		return err
	}
	res, err := query.Run(ix, q, query.Options{})
	if err != nil {
		var qe *query.Error
		if errors.As(err, &qe) {
			return usageError{err}
		}
		return err
	}
	var found []*index.Entry
	for _, g := range res.Groups {
		found = append(found, g.Tasks...)
	}
	roots, cycle := treeOf(ix, found)
	switch {
	case idsOnly:
		return a.printIDs(ix, flatten(roots, cycle))
	case tmpl != nil:
		return a.printFormat(ix, flatten(roots, cycle), tmpl)
	case a.jsonOut:
		out := make([]*taskJSON, 0, len(roots)+len(cycle))
		for _, n := range roots {
			out = append(out, nodeJSON(ix, n))
		}
		for _, e := range cycle {
			j := entryJSON(ix, e)
			j.InCycle = true
			out = append(out, j)
		}
		return a.printJSON(out)
	}
	var b strings.Builder
	st := a.style()
	for _, n := range roots {
		writeNode(&b, ix, st, n, "", "")
	}
	if len(cycle) > 0 {
		b.WriteString("\n== in a parent cycle\n")
		for _, e := range cycle {
			b.WriteString(treeLine(ix, st, e, false) + "\n")
		}
	}
	_, err = fmt.Fprint(a.stdout, b.String())
	return err
}

// treeOf builds the tree of the tasks found and of the ancestors that
// connect them to a root. Tasks in a parent cycle never reach a root; they
// are returned apart, by ID.
func treeOf(ix *index.Index, found []*index.Entry) (roots []*treeNode, cycle []*index.Entry) {
	match := map[model.ID]bool{}
	show := map[model.ID]bool{}
	for _, e := range found {
		match[e.ID] = true
		for cur := e; cur != nil && !show[cur.ID]; {
			show[cur.ID] = true
			if cur.Parent == nil {
				break
			}
			cur, _ = ix.Task(*cur.Parent)
		}
	}
	seen := map[model.ID]bool{}
	var build func(e *index.Entry) *treeNode
	build = func(e *index.Entry) *treeNode {
		seen[e.ID] = true
		n := &treeNode{e: e, context: !match[e.ID]}
		for _, c := range ix.Children(e.ID) {
			if show[c.ID] && !seen[c.ID] {
				n.children = append(n.children, build(c))
			}
		}
		return n
	}
	for _, r := range ix.Roots() {
		if show[r.ID] {
			roots = append(roots, build(r))
		}
	}
	for id := range show {
		if !seen[id] {
			e, _ := ix.Task(id)
			cycle = append(cycle, e)
		}
	}
	slices.SortFunc(cycle, func(x, y *index.Entry) int { return cmp.Compare(x.ID.String(), y.ID.String()) })
	return roots, cycle
}

func writeNode(b *strings.Builder, ix *index.Index, st style, n *treeNode, lead, childLead string) {
	b.WriteString(lead + treeLine(ix, st, n.e, n.context) + "\n")
	for i, c := range n.children {
		if i == len(n.children)-1 {
			writeNode(b, ix, st, c, childLead+"└─ ", childLead+"   ")
		} else {
			writeNode(b, ix, st, c, childLead+"├─ ", childLead+"│  ")
		}
	}
}

// treeLine is one task of the tree: short ID, status, kind and title.
func treeLine(ix *index.Index, st style, e *index.Entry, context bool) string {
	r := taskRow(ix, e)
	line := r[0] + "  " + r[1] + "  " + r[2] + "  " + r[5]
	if context {
		return st.dim(line)
	}
	return st.id(r[0]) + line[len(r[0]):]
}

func nodeJSON(ix *index.Index, n *treeNode) *taskJSON {
	j := entryJSON(ix, n.e)
	j.Context = n.context
	for _, c := range n.children {
		j.Children = append(j.Children, nodeJSON(ix, c))
	}
	return j
}

// flatten lists the tree in the order it is drawn, then the cycle.
func flatten(roots []*treeNode, cycle []*index.Entry) []*index.Entry {
	var out []*index.Entry
	var walk func(n *treeNode)
	walk = func(n *treeNode) {
		out = append(out, n.e)
		for _, c := range n.children {
			walk(c)
		}
	}
	for _, n := range roots {
		walk(n)
	}
	return append(out, cycle...)
}
```

```go
		Short: "Show a task",

	}
}

type commentJSON struct {
	ID      string    `json:"id"`
	Author  string    `json:"author"`
	Created time.Time `json:"created"`
	Body    string    `json:"body"`
}

type refJSON struct {
	Short string `json:"short"`
	Title string `json:"title"`
}

type showJSON struct {
	*taskJSON
	Body     string               `json:"body"`
	Watchers []string             `json:"watchers"`
	Repos    []string             `json:"repos"`
	Comments []commentJSON        `json:"comments"`
	Reverse  map[string][]refJSON `json:"reverse"`
}

// relation is one kind of task pointing at the task shown.
type relation struct {
	key   string // the name in JSON: blocks, or the property
	label string // the name in the text
	tasks []*index.Entry
}

func (a *app) show(arg string) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	var t *model.Task
	if e.Broken == "" {
		if t, err = s.Task(e.ID); err != nil {
			return err
		}
	}
	comments, err := liveComments(s, e.ID)
	if err != nil {
		return err
	}
	rels := reverse(ix, e.ID)
	if a.jsonOut {
		return a.printJSON(showOf(ix, e, t, comments, rels))
	}
	_, err = fmt.Fprint(a.stdout, a.showText(ix, e, t, comments, rels))
	return err
}

func liveComments(s *store.Store, id model.ID) ([]*model.Comment, error) {
	var out []*model.Comment
	for c, err := range s.Comments(id) {
		if err != nil {
			return nil, err
		}
		if c.DeletedAt == nil {
			out = append(out, c)
		}
	}
	return out, nil
}

// reverse finds the tasks that point at id, by relation.
func reverse(ix *index.Index, id model.ID) []relation {
	var out []relation
	if es := ix.Reverse(id, "blocked_by"); len(es) > 0 {
		out = append(out, relation{"blocks", "blocks", es})
	}
	for _, p := range ix.Schema().Props {
		if p.Type != schema.TypeTaskRef {
			continue
		}
		es := ix.Reverse(id, p.Name)
		if len(es) == 0 {
			continue
		}
		label := p.Name + " (from)"
		switch {
		case p.Inverse != "":
			label = p.Inverse
		case p.Symmetric && p.Label != "":
			label = p.Label
		case p.Symmetric:
			label = p.Name
		}
		out = append(out, relation{p.Name, label, es})
	}
	return out
}

// refName names the task id for a reader: its short ID and title.
func refName(ix *index.Index, id model.ID) string {
	if e, ok := ix.Task(id); ok {
		return ix.ShortID(id) + " " + e.Title
	}
	return id.String() + " (not found)"
}

func showOf(ix *index.Index, e *index.Entry, t *model.Task, comments []*model.Comment, rels []relation) *showJSON {
	j := &showJSON{taskJSON: entryJSON(ix, e), Watchers: []string{}, Repos: []string{}, Comments: []commentJSON{}, Reverse: map[string][]refJSON{}}
	if t != nil {
		j.Body, j.Watchers, j.Repos = t.Body, orEmpty(t.Watchers), orEmpty(t.Repos)
	}
	for _, c := range comments {
		j.Comments = append(j.Comments, commentJSON{c.ID.String(), c.Author, c.Created, c.Body})
	}
	for _, r := range rels {
		for _, x := range r.tasks {
			j.Reverse[r.key] = append(j.Reverse[r.key], refJSON{ix.ShortID(x.ID), x.Title})
		}
	}
	return j
}

func (a *app) showText(ix *index.Index, e *index.Entry, t *model.Task, comments []*model.Comment, rels []relation) string {
	st := a.style()
	var b strings.Builder
	b.WriteString(st.id(ix.ShortID(e.ID)) + "  " + e.Title + "\n")
	field := func(k string, vs ...string) {
		v := strings.Join(vs, ", ")
		if v == "" {
			v = "-"
		}
		fmt.Fprintf(&b, "  %-11s %s\n", k, v)
	}
	refs := func(ids []model.ID) []string {
		out := make([]string, len(ids))
		for i, id := range ids {
			out[i] = refName(ix, id)
		}
		return out
	}
	field("id", e.ID.String())
	field("key", e.Key)
	field("kind", e.Kind)
	field("status", e.Status)
	if e.Parent != nil {
		field("parent", refName(ix, *e.Parent))
	} else {
		field("parent")
	}
	field("assignees", e.Assignees...)
	if t != nil {
		field("watchers", t.Watchers...)
	}
	field("labels", e.Labels...)
	if t != nil {
		field("repos", t.Repos...)
	}
	field("blocked_by", refs(e.BlockedBy)...)
	sc := ix.Schema()
	for _, p := range e.Props {
		if sp, ok := sc.Prop(p.Key); ok && sp.Type == schema.TypeTaskRef {
			field(p.Key, refs(e.Targets(p.Key))...)
			continue
		}
		field(p.Key, p.Values...)
	}
	by := "-"
	if t != nil && t.CreatedBy != "" {
		by = t.CreatedBy
	}
	field("created", e.Created.Format(time.RFC3339)+" by "+by)
	field("updated", e.Updated.Format(time.RFC3339))
	if e.DeletedAt != nil {
		field("deleted", e.DeletedAt.Format(time.RFC3339))
	}
	if e.Broken != "" {

	}

		b.WriteString("\nProblems:\n")
		for _, p := range ps {
			fmt.Fprintf(&b, "  %s %s: %s\n", p.Code, p.Field, p.Msg)
		}
	}
	if len(rels) > 0 {
		b.WriteString("\nRelated:\n")
		for _, r := range rels {
			names := make([]string, len(r.tasks))
			for i, x := range r.tasks {
				names[i] = ix.ShortID(x.ID) + " " + x.Title
			}
			field(r.label, names...)
		}
	}
	if t != nil && strings.TrimSpace(t.Body) != "" {
		b.WriteString("\n" + strings.TrimRight(t.Body, "\n") + "\n")
	}
	if len(comments) > 0 {
		b.WriteString("\nComments:\n")
		for _, c := range comments {
			fmt.Fprintf(&b, "  %s  %s\n", c.Author, c.Created.Format(time.RFC3339))
			for _, l := range strings.Split(strings.TrimRight(c.Body, "\n"), "\n") {
				b.WriteString("    " + l + "\n")
			}
		}
	}
	return b.String()
}
```

```go
		}
```

```go
package main

import (
	"fmt"
	"slices"

	"github.com/spf13/cobra"

	"github.com/kukv/hedgehug/internal/model"
	"github.com/kukv/hedgehug/internal/store"
)

func (a *app) depCmd() *cobra.Command {
	cmd := &cobra.Command{Use: "dep", Short: "Manage what blocks a task", Args: cobra.NoArgs}
	for _, add := range []bool{true, false} {
		var blockedBy string
		use, short := "add <id> --blocked-by <id>", "Make a task blocked by another"
		if !add {
			use, short = "rm <id> --blocked-by <id>", "Stop a task being blocked by another"
		}
		sub := &cobra.Command{
			Use:   use,
			Short: short,
			Args:  exactArgs(1),
			RunE: func(_ *cobra.Command, args []string) error {
				if blockedBy == "" {
					return usageErrorf("--blocked-by is needed")
				}
				return a.dep(args[0], blockedBy, add)
			},
		}
		sub.Flags().StringVar(&blockedBy, "blocked-by", "", "the blocking task")
		cmd.AddCommand(sub)
	}
	return cmd
}

func (a *app) dep(arg, blockerArg string, add bool) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	b, err := a.resolve(ix, blockerArg)
	if err != nil {
		return err
	}
	if err := a.update(s, "dep", e.ID, func(tx *store.Tx) error {
		t, err := tx.Task(e.ID)
		if err != nil {
			return err
		}
		has := slices.Contains(t.BlockedBy, b.ID)
		switch {
		case add && has:
			return fmt.Errorf("%s is already blocked by %s", refName(ix, e.ID), refName(ix, b.ID))
		case add:
			t.BlockedBy = append(t.BlockedBy, b.ID)
		case !has:
			return fmt.Errorf("%s is not blocked by %s", refName(ix, e.ID), refName(ix, b.ID))
		default:
			t.BlockedBy = slices.DeleteFunc(t.BlockedBy, func(x model.ID) bool { return x == b.ID })
		}
		return tx.PutTask(t)
	}); err != nil {
		return err
	}
	return a.printTask(ix, e.ID, "Updated")
}
```

```go
// descendants returns the tasks under id for which follow is true, going
// down only through those, depth first in rank order. A parent cycle stops
// the walk.
func descendants(ix *index.Index, id model.ID, follow func(*index.Entry) bool) []*index.Entry {
	seen := map[model.ID]bool{id: true}
	var out []*index.Entry
	var walk func(model.ID)
	walk = func(p model.ID) {
		for _, c := range ix.Children(p) {
			if seen[c.ID] || !follow(c) {
				continue
			}
			seen[c.ID] = true
			out = append(out, c)
			walk(c.ID)
		}
	}
	walk(id)
	return out
}

func (a *app) rm(arg string) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	if e.DeletedAt != nil {
		return fmt.Errorf("%s is already deleted", refName(ix, e.ID))
	}
	targets := []*index.Entry{e}
	for _, d := range descendants(ix, e.ID, func(*index.Entry) bool { return true }) {
		if d.DeletedAt == nil {
			targets = append(targets, d)
		}
	}
	now := a.now().Truncate(time.Second)
	if err := a.update(s, "rm", e.ID, func(tx *store.Tx) error {
		for _, x := range targets {
			t, err := tx.Task(x.ID)
			if err != nil {
				return err
			}
			t.DeletedAt = &now
			if err := tx.PutTask(t); err != nil {
				return err
			}
		}
		return nil
	}); err != nil {
		return err
	}
	return a.printAffected(ix, e, targets, "Deleted", true)
}

func (a *app) restore(arg string) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	if e.DeletedAt == nil {
		return fmt.Errorf("%s is not deleted", refName(ix, e.ID))
	}
	if e.Parent != nil {
		if p, ok := ix.Task(*e.Parent); ok && p.DeletedAt != nil {
			return fmt.Errorf("the parent %s is deleted; restore %s first", refName(ix, p.ID), ix.ShortID(p.ID))
		}
	}
	at := *e.DeletedAt
	targets := append([]*index.Entry{e}, descendants(ix, e.ID, func(d *index.Entry) bool {
		return d.DeletedAt != nil && d.DeletedAt.Equal(at)
	})...)
	if err := a.update(s, "restore", e.ID, func(tx *store.Tx) error {
		for _, x := range targets {
			t, err := tx.Task(x.ID)
			if err != nil {
				return err
			}
			t.DeletedAt = nil
			if err := tx.PutTask(t); err != nil {
				return err
			}
		}
		return nil
	}); err != nil {
		return err
	}
	return a.printAffected(ix, e, targets, "Restored", true)
}

func (a *app) purge(arg string, yes bool) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	if e.DeletedAt == nil {
		return fmt.Errorf("%s is not deleted; delete it with hedgehug rm first", refName(ix, e.ID))
	}
	targets := append([]*index.Entry{e}, descendants(ix, e.ID, func(*index.Entry) bool { return true })...)
	for _, d := range targets[1:] {
		if d.DeletedAt == nil {
			return fmt.Errorf("%s under it is not deleted", refName(ix, d.ID))
		}
	}
	if !yes {
		if err := a.confirm(ix, targets); err != nil {
			return err
		}
	}
	if err := a.update(s, "purge", e.ID, func(tx *store.Tx) error {
		for _, x := range targets {
			if err := tx.RemoveTask(x.ID); err != nil {
				return err
			}
		}
		return nil
	}); err != nil {
		return err
	}
	return a.printAffected(ix, e, targets, "Purged", false)
}

// confirm asks on the terminal before a purge.
func (a *app) confirm(ix *index.Index, targets []*index.Entry) error {
	if !a.isTerminal(a.stdin) {
		return usageErrorf("purge removes files for good; give --yes to go ahead")
	}
	var b strings.Builder
	fmt.Fprintf(&b, "Purge %d tasks for good?\n", len(targets))
	for _, x := range targets {
		b.WriteString("  " + refName(ix, x.ID) + "\n")
	}
	b.WriteString("[y/N] ")
	if _, err := fmt.Fprint(a.stderr, b.String()); err != nil {
		return err
	}
	line, err := bufio.NewReader(a.stdin).ReadString('\n')
	if err != nil && line == "" {
		return errors.New("purge canceled")
	}
	if ans := strings.ToLower(strings.TrimSpace(line)); ans != "y" && ans != "yes" {
		return errors.New("purge canceled")
	}
	return nil
}

// printAffected prints the tasks a write changed: as JSON (read again
// after the write when refresh is true, as they were otherwise), or as one
// line about the task named.
func (a *app) printAffected(ix *index.Index, e *index.Entry, targets []*index.Entry, verb string, refresh bool) error {
	if a.jsonOut {
		if refresh {
			if err := ix.Refresh(); err != nil {
				return err
			}
		}
		out := make([]*taskJSON, 0, len(targets))
		for _, x := range targets {
			cur := x
			if refresh {
				cur, _ = ix.Task(x.ID)
			}
			out = append(out, entryJSON(ix, cur))
		}
		return a.printJSON(out)
	}
	line := fmt.Sprintf("%s %s %s", verb, a.style().id(ix.ShortID(e.ID)), e.Title)
	switch n := len(targets) - 1; n {
	case 0:
	case 1:
		line += " and 1 task under it"
	default:
		line += fmt.Sprintf(" and %d tasks under it", n)
	}
	_, err := fmt.Fprintln(a.stdout, line)
	return err
}
```

```go
import (
	"fmt"

func (a *app) mvCmd() *cobra.Command {
	var parent, before, after string
	var root bool
	cmd := &cobra.Command{
		Use:   "mv <id> [--parent <id> | --root] [--before <id> | --after <id>]",
		Short: "Move a task under another parent or among its siblings",
		Args:  exactArgs(1),
		RunE: func(_ *cobra.Command, args []string) error {
			switch {
			case parent != "" && root:
				return usageErrorf("give --parent or --root, not both")
			case before != "" && after != "":
				return usageErrorf("give --before or --after, not both")
			case parent == "" && !root && before == "" && after == "":
				return usageErrorf("say where to: --parent, --root, --before or --after")
			}
			return a.mv(args[0], parent, root, before, after)
		},
	}
	f := cmd.Flags()
	f.StringVar(&parent, "parent", "", "the new parent")
	f.BoolVar(&root, "root", false, "move to the top level")
	f.StringVar(&before, "before", "", "put it just before this sibling")
	f.StringVar(&after, "after", "", "put it just after this sibling")
	return cmd
}

func (a *app) mv(arg, parentArg string, root bool, before, after string) error {
	s, ix, err := a.open()
	if err != nil {
		return err
	}
	e, err := a.resolve(ix, arg)
	if err != nil {
		return err
	}
	parent := e.Parent
	switch {
	case root:
		parent = nil
	case parentArg != "":
		p, err := a.resolve(ix, parentArg)
		if err != nil {
			return err
		}
		parent = &p.ID
	}
	rank, err := a.rankAt(ix, e.ID, parent, before, after)
	if err != nil {
		return err
	}
	if err := a.update(s, "mv", e.ID, func(tx *store.Tx) error {
		t, err := tx.Task(e.ID)
		if err != nil {
			return err
		}
		t.Parent, t.Rank = parent, rank
		return tx.PutTask(t)
	}); err != nil {
		return err
	}
	return a.printTask(ix, e.ID, "Moved")
}

// rankAt returns the rank for id under parent: just before or after a
// sibling, or after every sibling.
func (a *app) rankAt(ix *index.Index, id model.ID, parent *model.ID, before, after string) (model.Rank, error) {
	if before == "" && after == "" {
		return endRank(ix, parent, id)
	}
	ref := before
	if ref == "" {
		ref = after
	}
	x, err := a.resolve(ix, ref)
	if err != nil {
		return "", err
	}
	sib := siblings(ix, parent, id)
	i := slices.IndexFunc(sib, func(e *index.Entry) bool { return e.ID == x.ID })
	if i < 0 {
		return "", fmt.Errorf("%s is not under the same parent", refName(ix, x.ID))
	}
	if before != "" {
		var prev model.Rank
		if i > 0 {
			prev = sib[i-1].Rank
		}
		return model.Between(prev, x.Rank)
	}
	var next model.Rank
	if i+1 < len(sib) {
		next = sib[i+1].Rank
	}
	return model.Between(x.Rank, next)
}
```
