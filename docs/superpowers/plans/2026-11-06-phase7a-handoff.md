# フェーズ 7a の引き継ぎ（2026-11-06 時点）

7a（性能）は plan の Task 1〜6 を実装した。1万タスクの Store で、`hh ls` の6場面すべてが WSL と mac の両方で目標内に入った。結果は spec の「計測の結果」にある。

## plan から変えた点

- `commitReparent` は、プロジェクトを `epic` にして別のプロジェクトの下に移す。プロジェクトはルートにしか置けない
- `BenchmarkLs` は `List` の件数が 10,000 であることを確かめる

## 実装で分かったこと

- 全件の読み直しの時間はほぼ pack の `pread` である。`objectReader` は並行に読めるので、`index.readEach` で並列にした。WSL で 1,033ms が 598ms になった
- `index` への書き込みは順次のまま。並列に動くのは読み込みと解析だけである
- mac では、ビルドした直後のバイナリの最初の実行だけが約 350ms かかる

## 親設計との関係

全件の作り直しと全件の再検査の 1 秒の目標は、spec の承認後に親設計へ反映した（rev 396）。Homebrew、Scoop、PowerShell の記述も同じときに消した。
