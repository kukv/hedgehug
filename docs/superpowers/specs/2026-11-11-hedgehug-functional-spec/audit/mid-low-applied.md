# 中・低 134 件の反映で Claude が補った細部(2026-11-12)

ユーザーの指示「全部推奨どおり」で、`mid-low-decisions.md` の「残る」134 件の推奨案を仕様 01〜08 に反映した。推奨案に書いていない細部は、既存の書き方にいちばん近い形で Claude が補った。以下はその一覧で、ユーザーが決めたものではない。見直すときはここから辿る。

## 全体
- 134 件すべてが、どれかのファイルに反映されたか、すでに書いてあると確かめた。
- 「モックからの変更点」の表のモック欄は、モックの振る舞いが推奨案から分からないものを「決まっていない」「記載なし」とした。推定で書いたものは各ファイルの項に挙げる。

## 01 全体の前提
- Q-035・Q-126: ログイン名の段落を、初期値の決め順、入力して追加するとこのマシンのログイン名になること、注意書き、設定「一般」での確認、の順に書き直した。
- Q-038: 保存の作者のメールアドレスは `{ログイン名}@hedgehug.invalid`、人でない保存は `bot@hedgehug.invalid`。実在しないアドレスなので「本物のメールアドレスは入れない」と両立するとみなした。
- Q-039: 自動化・診断の修復の参照は、行番号ではなく文書番号(03・08)で書いた。
- Q-116・Q-089・Q-190: 閲覧のみの Store の総則、見直す操作、帯を出す 4 か所は、閲覧のみの節の箇条に足した。
- Q-092・Q-162: 「書き込める人なら誰でも変更・削除できる」は、書き込みの単位の節に独立した段落で置いた。

## 02 アイテムとプロジェクト
- Q-037: メンバーに加える対象に、履歴の操作者・作成者を入れた(置き換えの表には入れない)。同時に同じ人を加えたときの統合は 06 に任せた。
- Q-057: 移動先に remote がないときの保存の順を「移動先に保存してから移動元に保存」とした。
- Q-052: 書きかけがあるあいだ自動の再読み込みを止めることは、説明の節に 1 行だけ書き、詳細は 06・08 を参照させた。
- Q-073: 旧 ID で見つからないときの文と解決の規則を、旧 ID の節に書き、プロジェクトの移動からは参照させた。
- Q-075: 別の Store へ移すとき、移すもの同士の関連は残す(Store をまたぐ関連だけを解除する)と読んだ。
- 記録の表に「プロジェクトの復元」「リポジトリの追加・削除」の行を足した。

## 03 ワークスペースの設定
- Q-076: 削除の確認の「削除済みの {M} 件」は、削除済みのプロジェクト・アイテム・スプリント・リリースの合計。
- Q-109: 旧い接頭辞の記録の段落を、接頭辞の変更の節に置いた。確認ダイアログには、件数 0 のときも「旧い接頭辞でも検索できます」を入れた。
- Q-110・Q-186: 初期ステータスの分類を完了だけでなく中止に変えた場合も同じ扱いにした。
- Q-114: 変更点表のモック欄「当てるたびに置き換える」は推定。

## 04 検索とレイアウト
- Q-047: 同じ 1 件を 2 人が別の位置に動かしたときは、保存時刻があとの位置が勝つ(06)と 1 文。順位が同じときの並べ方は 3 か所に書いた。
- Q-097: `sort:` が効く範囲は 04:239 の記述で足りるとし、04:254・04:584 は直していない。
- Q-124: `store:旧名` の書き換えは、キーの表の `store` の行に書いた。検索ヘルプの行は直していない。
- Q-179: 日付が変わったときの更新は、04 の対象(マイタスク、期限の強調、「期限切れ」の件数、ガントの今日の線)だけを書いた。

## 05 計画とレポート

## 06 同期・通知・アクティビティ

- Q-105: 書き換えの通知文の書き換え先は空欄 {書き換え先}。

- Q-065: 受信箱で、対象がアイテムでもプロジェクトでもないときは、Store の点とワークスペース名を出す。
- Q-143: 受信箱の件数の上限は、新しい「件数」の節に書いた。

## 07 GitHub 連携
- Q-049: 時計のずれの比較は、通信に使うアカウントの節の末尾に 1 文。警告の文言と場所は 06・08。
- Q-058: gh CLI の 10 秒の時間切れは、認証の確認の表に 1 行足した。

- Q-034: メンバーの重複を診断で直したときは、アイテムではないので通知を出さない。診断が調べる対象に「Store のメンバー」を足した。
- Q-205: 直せる件数が 0 のとき、「閲覧のみの Store です」の添え書きは、閲覧のみの分があるときだけ出す。
- Q-067: スプリント・リリースを変えたときのトーストは、アイテムの行の復元にだけ書いた。
- Q-052: 「接続できると、自動でこの画面を再読み込みします」の文言は変えていない(書きかけがあるときは保存・キャンセルのあとに再読み込みする)。
- Q-064: 「最初の同期で「同期できません」と表示する」(08:138)は、推奨案に指示がないのでそのまま。
- Q-124: 変更点表のモック欄「変更できない」は推定。
