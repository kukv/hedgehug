## 当てはめを確かめて、変えなかったもの

- 「接頭辞」「#」「メイン」「ステータス」「移動」「WS」で全文を検索した。接頭辞の記述は、同期の修復の表の接頭辞の行(WEB → WEB2。接頭辞はすべてのワークスペースにあるので、そのまま)と、修復の決まりの列挙、通知の開く先だけで、直す必要はなかった。`#` は GitHub の PR 番号(`{リポジトリ}#{番号}`)だけで、`#12`・`#P1` の ID の書き方はこの文書にない。「メイン」はこの文書にない。
- 移動のステータスの置き換え(新しい決定 1)は、06 の「別の Store へ移動したものと重なったとき」の規則(移動の保存が勝つだけ)に触れないので、直していない。同期の修復で子を移す場合だけ、13 のとおり書いた。
