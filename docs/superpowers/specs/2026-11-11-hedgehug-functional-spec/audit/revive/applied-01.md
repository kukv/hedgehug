## 他ファイルへの依頼

1. 03・02(旧い画面のアドレスの解決): 03 の転送の記録の文と 02 の「旧 ID から辿れる場所」は、旧い画面のアドレスを「記録の内部 ID」で探すと書いている。01 のアドレスは、Store 名と画面の ID(ワークスペースは接頭辞。旧い ID・旧い接頭辞でもよい)で指すので(x-check Y8)、「旧い画面のアドレスは、記録の内部 ID で…探し」を「旧い ID(接頭辞)で、転送の記録をたどって…探し」の形に合わせてほしい。ワークスペースを旧い接頭辞のアドレスで開けることも、03 の接頭辞の変更の節に 1 文あるとよい。
