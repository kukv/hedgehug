迷ったが当てはめにしたもの(当てはめた規則を添える)。

- N358・N359: 閲覧のみの Store でキーを押しても何も起こさない。トーストなし。
  - 規則: 01「操作してから断るのではなく、操作できない見た目にする」。04「無効にしたものには「閲覧のみの Store です」と添える」。
- N391・N412: 閲覧のみの Store では、パレットの書き込み系の項目を出さない。
  - 規則: 02 パレットは、閲覧のみの Store のワークスペースを候補から出さない(02 の 130 行、489 行)。出さない形に既に合っている。
- N371: ツリーで Space を押すと、完了なら未着手、完了でなければ完了にする。
  - 規則: 02「Step のチェック」と同じ形。制約違反は「ステータスの変更」の文言のトーストで断る。
- N376: Shift+Ctrl+S は入力中・ダイアログ中でも使える。
  - 規則: 06「手動の同期でも、編集中の入力欄の内容は書き換えない」。01 の C・/・Ctrl+K は入力中とダイアログ中に使えないが、それは入力を奪うキーのため。同期は入力を奪わない。
- N401: パレットの「検索で開く」で、検索画面に残していた絞り込みが置き換わる。
  - 規則: 04。絞り込みは画面の状態で、Store に保存するものではない(01「画面の状態の変更は Store を変えない」)。
- N444: ダイアログやパレットを開いたまま戻るを押すと、閉じてから移る。入力は保存しない。
  - 規則: 02 の確認ダイアログ(説明の編集中の「入力を破棄」)は説明の入力欄だけ。作成ダイアログは閉じれば破棄される。Q20 を採用したときだけ要る。
- N480: remote が空で存在する GitHub のリポジトリは、作らずにそのまま使う。
  - 規則: 06 の 94 行、08 の 87 行「remote が空のリポジトリは最初の送信として認める」。
- N505・N506: 既定の Store は、書き込める Store を最初に追加したときに付き、削除しても自動では移さない。
  - 規則: アイテム作成の初期値と同じ順(書き込める Store の先頭)に落ちる。見える結果は、パレットの「ワークスペースを追加」の Store の初期値だけ。
- N525・N526: コピーを残して解除したあとの取り込み直しでは、色・非表示・ミラーを引き継がない。
  - 規則: 01「マシンごとに持つもの」は、このマシンから削除すれば消える。
- N454: アカウントがない、または問い合わせられないときは、書き込める Store として取り込む。
  - 規則: 08「Store を追加」の「あなた」と閲覧のみの判定(権限を問い合わせられないときは書き込める扱い)に合わせる。
