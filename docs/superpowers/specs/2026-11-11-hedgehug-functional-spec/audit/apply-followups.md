## A. 判断が要るもの

2026-11-12 追記: Issue の取り込み・同期・作成をなくした(リンクだけ残す)。F-2・B-9・B-12・C-4 は不要になった。F-3 の推奨「未着手の既定に戻す」は誤りなので取り下げ、「削除と既定の指定が同時に起きたら、削除を取り消す(P1 と同じ)」に改めた。

| ID | 画面と操作 | 何が起きるか | 推奨 |
|---|---|---|---|
| F-1 | コメント・作業時間・履歴などの人の表示(01:148) | 別 Store への移動でメンバーを載せることにし、メンバーの削除もないので、「不明なユーザー」はふつうの使い方では出なくなった | 規則は残す。hedgehug を通さずに git で書き換えた Store など、一覧にない人を指すデータへの備えとする |
| F-2 | 受信箱「自動化」の通知。自動化が、Issue が開いているアイテムを Done にしようとして止まったとき | ワークフローの制約で止まったときの通知には「制約を無視して Done にする」がある。Issue が開いたままでこれを押すと、次に GitHub を読んだときに戻される | このときはボタンを出さず、「変更しない」だけにする |
